# Student Management System using Python and SHAP

## Project Overview

This project is developed as part of the Python for Data Science (PDS) Project-Based Learning (PBL). It demonstrates student record management, data analysis, visualization, and machine learning.

## Features

* Student record management: Create, read, search, update, and delete records.
* SQLite database integration.
* Data cleaning and preprocessing using Pandas.
* Data visualization using Matplotlib and Seaborn.
* Student performance analysis.
* Random Forest classification for identifying students who meet a defined academic-risk criterion.
* SHAP (SHapley Additive exPlanations) for interpreting machine-learning predictions.
* Export of results to CSV files.

## Technologies Used

* Python
* Google Colab / Jupyter Notebook
* Pandas and NumPy
* Matplotlib and Seaborn
* SQLite
* Scikit-learn
* SHAP

## How to Run

1. Download `PDS_PBL_3.ipynb` from this repository.
2. Open [Google Colab](https://colab.research.google.com/).
3. Upload the notebook.
4. Install any required libraries if prompted.
5. Run the cells in order.

## Dataset

The notebook uses simulated student data for demonstration and educational purposes. Its academic-risk classification is based on the criterion defined in the notebook and is not a validated assessment of real students.
